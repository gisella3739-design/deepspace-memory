# ✦ 深空记忆 · 需求文档（PRD）

> 版本 v1.0 · 2026-09-23
> 项目：deepspace-memory（私人朋友圈风格小站 · 恋与深空主题）

## 1. 背景与目标

朋友做的古早私人网站 [taiwan_memory](https://github.com/jia050904/taiwan_memory)（起点是整理台湾旅游攻略，长成了"我们自己小型朋友圈"）启发了一个同类站点：把日记、攻略收藏、留言、便签收进一个自己的小宇宙。整体风格换上《恋与深空》主题色，首页常驻夏以昼。

**目标**：一个零后端、零成本、可写进 vibecoding 作品集的个人小站。

## 2. 用户与场景

- **用户**：站长本人 + 少数朋友（访问者）
- **场景**：发日常碎碎念和照片；收藏看到的攻略/店铺链接；导入写好的 Word 攻略文档随手看；朋友来访留言

## 3. 功能需求

### P0（首版必须，已全部实现）

| 模块 | 需求 | 状态 |
|---|---|---|
| DIARY | 发文字 + 最多 9 张照片 + 评论；照片自动压缩；分页加载（每次 3 条）；照片点开看大图；可删除 | ✅ |
| LINKS | 贴链接收藏，填标题、选分类（攻略/吃/玩/周边/其他）；按分类筛选 | ✅ |
| HOME·留言板 | 朋友留言（署名可空 → 匿名小星星），首页展示最新 6 条 | ✅ |
| HOME·Memo | 随手记，最多 30 条，可删除 | ✅ |
| HOME·夏以昼 | 常驻卡片：手绘 SVG 头像 + 语录轮播（点击换一句） | ✅ |
| 风格 | 恋与深空主题：深空蓝紫底色 × 星尘金点缀 + 闪烁星空背景 | ✅ |

### P1（首版实现，体验增强）

| 模块 | 需求 | 状态 |
|---|---|---|
| GUIDES | 导入 .docx Word 攻略，网页内预览（docx-preview 渲染），保留导入记录 | ✅ |
| HOME·BGM | 播放器（上一首/播放暂停/下一首），曲目读 `songs/manifest.json` | ✅ |
| 移动端 | ≤760px 单列布局 | ✅ |
| about 弹窗 | 说明站点来源与数据归属 | ✅ |

### P2（后续迭代方向，未实现）

- 多设备共享：接 Firebase Firestore（links / posts / guideDocs / memos / guestbook 五个 collection，照 taiwan_memory 的方案）
- 图片走 Cloudinary，摆脱 localStorage 5MB 配额
- 访客身份体系（每人自己的署名和头像）
- TRAVEL 式"贴链接自动抓标题封面"（需要后端代理解决跨域与反爬）
- 相册墙 / 时间轴视图

## 4. 非功能需求

- **零后端**：纯静态，GitHub Pages / Render / Netlify 任一免费托管可跑
- **数据归属**：全部存浏览器 localStorage（键前缀 `dsm_`），不上传任何服务器
- **成本**：0 元（仅 docx-preview / JSZip 两个 CDN 库）
- **版权红线**：不含官方美术素材（头像为手绘 SVG）；不托管受版权保护的音频

## 5. 数据模型（localStorage）

| 键 | 内容 | 上限 |
|---|---|---|
| `dsm_posts` | 日记：text / photos(base64) / comments / ts | 无硬限（受配额约束） |
| `dsm_links` | 收藏：url / title / cat | — |
| `dsm_guestbook` | 留言：name / msg / ts | 50 |
| `dsm_memos` | 便签：text | 30 |
| `dsm_guides` | 攻略导入记录：name / ts | 20 |

## 6. 风格规范

- 底色 `#0d0a2a → #241a5e` 渐变；卡片 `rgba(30,22,74,.82)` + 紫边框
- 强调色：星尘金 `#ffd98a`（标题/点缀）、星紫 `#b79bff`（按钮/链接）
- 圆角 16px、按钮胶囊形；星空背景 90 颗星随机闪烁

## 7. 验收标准

- [x] 本地 `python3 -m http.server` 打开，五个模块全部可交互
- [x] 日记/收藏/留言/memo 写入 localStorage 并正确回显
- [x] 无 JS 报错（CDN 资源离线时优雅降级）
- [x] GitHub Pages 可直接部署，无需构建步骤
